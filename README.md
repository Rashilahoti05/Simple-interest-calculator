# Simple Interest Calculator

## Project Description
The Simple Interest Calculator is a simple Bash-based project that calculates simple interest using the principal amount, annual rate of interest, and time period in years.

## Formula
Simple Interest = (Principal * Rate * Time) / 100

## Input
The calculator uses the following inputs:
- Principal: The initial amount of money
- Rate: The annual rate of interest in percentage
- Time: The time period in years

## Output
The calculated simple interest.

## Example
Given:
- Principal = 1000
- Rate = 5%
- Time = 2 years

Calculation:
Simple Interest = (1000 * 5 * 2) / 100
Simple Interest = 100
